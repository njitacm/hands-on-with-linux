# Section 3: Permissions, Processes & System Management

You can work with files. Now it's time to understand what's happening *under the hood* — who's allowed to do what, what programs are running, and how the system is doing.

This section gives you the knowledge to manage a Linux system, not just use it.

## What You'll Learn

- How Linux controls access to files through permissions
- How users and groups work and what sudo does
- How to view, manage, and control running processes
- How environment variables configure your shell and programs
- How to check on system resources like disk, memory, and CPU
