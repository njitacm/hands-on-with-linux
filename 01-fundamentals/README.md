# Section 1: Linux Fundamentals & Navigation

Welcome to Section 1! This is where your Linux journey begins. By the end of this section, you'll be comfortable opening a terminal, navigating the file system, reading files, creating your own directories, and knowing where to look when you need help.

No prior experience is required — just a terminal and some curiosity.

## What You'll Learn

- How the terminal works and what the prompt is telling you
- Navigating directories and understanding the Linux file system hierarchy
- Viewing and inspecting file contents from the command line
- Creating files and directories to organize your work
- Finding documentation and help for any command

## Challenges

| # | Challenge | Description |
|---|-----------|-------------|
| 1 | [Getting Started](./01-getting-started/) | Meet the terminal and run your first commands |
| 2 | [File System Navigation](./02-navigation/) | Move around the file system with confidence |

| 4 | [Creating & Organizing](./04-directories/) | Build directory structures and create files |
| 5 | [Getting Help](./05-getting-help/) | Find documentation for any command |

## How to Work Through This Section

1. Start with Challenge 1 and work through them in order
2. Read each challenge's README carefully
3. **Type the commands yourself** — don't copy-paste
4. Try the exercises at the end of each challenge
5. Experiment! Try variations of commands to see what happens
