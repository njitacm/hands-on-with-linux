# Section 4: Shell Scripting & Automation

Everything you've learned so far has been interactive — one command at a time. Now you'll learn to put commands into **scripts** that run automatically, make decisions, repeat tasks, and solve real problems.

This is where you go from Linux user to Linux power user.

## What You'll Learn

- Write and run your own bash scripts
- Add logic with conditionals and branching
- Automate repetitive work with loops
- Organize code into reusable functions
- Tackle real-world automation tasks with everything you've learned

## Challenges

| # | Challenge | Description |

| 1 | [Basic Scripts](./01-basic-scripts/) | Create your first shell scripts |
| 2 | [Conditionals](./02-conditionals/) | Add logic and decision-making to scripts |
| 3 | [Loops](./03-loops/) | Iterate and repeat operations |
| 4 | [Functions & Arguments](./04-functions/) | Create reusable code |
| 5 | [Putting It All Together](./05-capstone/) | Real-world scripting and automation |

## Prerequisites

You should be comfortable with all material from Sections 1-3, especially:

- Working with files and text processing tools
- Pipes and redirection
- File permissions (making scripts executable)
- Environment variables
