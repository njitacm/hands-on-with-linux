# Section 2: File Operations & Text Processing

In Section 1 you learned to navigate and read files. Now you'll learn to **do things** with them — copy, move, delete, edit, search, transform, and combine commands together into powerful pipelines.

This section covers the everyday toolkit of anyone who works on the command line.

## What You'll Learn

- Copy, move, rename, and delete files and directories safely
- Edit files directly from the terminal using vim and nano
- Search for files and text patterns across your system
- Process, compare, and transform text data
- Chain commands together with pipes and redirection

## Prerequisites

You should be comfortable with the material from [Section 1: Linux Fundamentals & Navigation](../01-fundamentals/), specifically:

- Navigating with `cd`, `pwd`, and `ls`
- Viewing files with `cat`, `less`, `head`, `tail`
- Creating directories with `mkdir` and files with `touch`
